# Expense Tracker AI

A modern expense tracking application built with React, Vite, and Ant Design. It helps users capture expenses, review analytics, and export reports.

## Features

- Add, edit, and delete expenses
- Date, amount, category, and description tracking
- Local storage persistence for demo usage
- Summary cards for total spending and monthly spend
- Category-based analytics and visual breakdown
- Search and filtering by category and date range
- CSV export for expense data
- Responsive professional UI for desktop and mobile

## Getting started

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open the local URL shown in the terminal (typically http://localhost:5173)

## Build for production

npm run build

## Testing the features

- Add a new expense using the form
- Edit an item from the table actions
- Filter by category or date range
- Search by description
- Export the filtered list to CSV
- Delete an item and verify it is removed from the dashboard and table

## Notes

This is a front-end demo using browser localStorage to persist data.
